03 Description of Software

JAGY provides an automated AI video clipping, vertical reframing, subtitling, and multi-network syndication engine. The software is designed to run locally on the user's desktop hardware, interacting with third-party APIs (such as Google Gemini, yt-dlp, FFmpeg, and YouTube API Services) as configured by the user.
